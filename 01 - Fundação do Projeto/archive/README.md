# archive/

Esta pasta está reservada para armazenar **versões antigas** do projeto Lumia
ao longo do seu desenvolvimento (por exemplo, snapshots de etapas anteriores
antes de mudanças estruturais importantes).

Nesta fase (Etapa 1), a pasta está **intencionalmente vazia** — nenhuma
versão anterior existe ainda. Ela será utilizada em etapas futuras, conforme
necessário, sempre seguindo as regras definidas em `docs/PROJECT_RULES.md`.
