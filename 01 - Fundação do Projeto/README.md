# Lumia

Lumia é um aplicativo premium para guardar memórias pessoais — fotos, textos,
vídeos e áudios — em um lugar calmo, elegante e nostálgico.

> Este projeto é desenvolvido em 7 etapas, sempre evoluindo a partir da
> versão anterior. Antes de qualquer alteração, leia obrigatoriamente os
> documentos em [`docs/`](./docs), especialmente
> [`docs/AI_MEMORY.md`](./docs/AI_MEMORY.md) e
> [`docs/PROJECT_RULES.md`](./docs/PROJECT_RULES.md).

## Stack

- React + Vite + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Scripts

```bash
npm install
npm run dev       # ambiente de desenvolvimento
npm run build     # build de produção
npm run preview   # pré-visualização do build
```
