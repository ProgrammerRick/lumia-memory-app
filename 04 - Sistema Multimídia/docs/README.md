# docs/ — Documentação viva do Lumia

Esta pasta contém a documentação de referência do projeto. Deve ser lida
integralmente antes de iniciar qualquer nova etapa de desenvolvimento.

- **AI_MEMORY.md** — documento mais importante; estado atual do projeto e
  contexto essencial para qualquer IA que continue o desenvolvimento.
- **PROJECT_RULES.md** — regras permanentes e definitivas do projeto.
- **PRODUCT_VISION.md** — visão de produto, público-alvo e identidade de marca.
- **DESIGN_SYSTEM.md** — fonte de verdade visual (cores, tipografia,
  espaçamento, glass, sombras, animações, componentes).
- **ARCHITECTURE.md** — estrutura de pastas, fluxo da aplicação e padrões de código.
- **ROADMAP.md** — as 7 etapas planejadas do produto e seu progresso.
- **CHANGELOG.md** — histórico de mudanças por etapa.
