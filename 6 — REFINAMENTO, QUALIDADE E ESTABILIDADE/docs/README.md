# Lumia — Documentação

Este diretório contém a documentação viva do projeto Lumia. Leia sempre,
nesta ordem, antes de iniciar trabalho em uma nova etapa:

1. `PROJECT_RULES.md` — regras permanentes do projeto.
2. `PRODUCT_VISION.md` — visão de produto e identidade.
3. `DESIGN_SYSTEM.md` — fonte de verdade visual.
4. `ARCHITECTURE.md` — estrutura técnica e de pastas.
5. `ROADMAP.md` — etapas concluídas e futuras.
6. `AI_MEMORY.md` — estado atual do projeto (o mais importante).
7. `CHANGELOG.md` — histórico detalhado de mudanças por etapa.

Todos esses documentos devem ser mantidos atualizados ao final de cada etapa.
