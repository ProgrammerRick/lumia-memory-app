# archive/

Esta pasta está reservada para armazenar **versões antigas** do projeto Lumia
ao longo do seu desenvolvimento (por exemplo, snapshots de etapas anteriores
antes de mudanças estruturais importantes).

Até a Etapa 4, a pasta permanece **intencionalmente vazia** — nenhuma versão
anterior precisou ser arquivada. Ela será utilizada em etapas futuras,
conforme necessário, sempre seguindo as regras definidas em
`docs/PROJECT_RULES.md`.
