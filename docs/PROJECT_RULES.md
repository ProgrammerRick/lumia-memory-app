# PROJECT RULES - LUMIA

## Regra principal

Este projeto deve evoluir mantendo sua identidade original.

## Nunca fazer sem autorização:

- alterar design principal
- trocar identidade visual
- remover funcionalidades existentes
- mudar arquitetura

## Princípios:

- código limpo
- alta performance
- experiência premium
- interface emocional
- responsividade

## Desenvolvimento:

Antes de grandes mudanças:
- explicar impacto
- informar arquivos modificados
- aguardar aprovação
