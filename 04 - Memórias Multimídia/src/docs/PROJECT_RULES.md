# PROJECT_RULES

## Objetivo
Desenvolver o Lumia Memory App de forma incremental.

## Regras
- Não remover funcionalidades existentes.
- Evoluir o código sem reescrever desnecessariamente.
- Mobile-first.
- Offline-first.
- Sem login, backend, Firebase, Supabase ou APIs externas nas primeiras versões.
- Manter arquitetura organizada e componentes reutilizáveis.
